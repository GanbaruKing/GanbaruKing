### 作品

**[BloodMaze](https://github.com/GanbaruKing/BloodMazeMod-StS2)** — Slay the Spire 2 追加キャラクター MOD

戦闘をまたいで持ち越す独自リソース「MP」を中核にした、新キャラクター「Revenant」を追加する MOD。
A character mod built around "MP," a resource that carries across battles.

- 独自カード **88 枚**・新規バフ/デバフ・協力モード対応
- ゲーム本体と BaseLib を**デコンパイルして一次情報を直接取得**
- Harmony パッチで公式 UI を拡張し、独自リソースの永続化を実装
